# Proyecto Cliente.

## Contexto Proyecto.

Desarrollo de una aplicación web para la gestión de un **centro de estética** con **React** que ofrece servicios de ``manicura``, ``pedicura`` y ``maquillaje``.

### La app debe permitira:

- Administrar sus productos.
- Organizar las reservas de los clientes.
- Gestionar los horario.
- Trabajo de las empleadas.
- Consultar la situación económica del negocio.

> Interfaz ``moderna, intuitiva y fácil de utilizar``.
>Uso de `REACT` y `JavaScript`.

### Se valora:
- Que la App funcione.
- Organización del codigo.
- Calidad de soluciones.
- Validacion de datos.
- Tratamiento de errores.
- Justificacion de decisiones tomadas.
